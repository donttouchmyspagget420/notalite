NotaLite · Mockups ← Galería completa

Mockups individuales

Un archivo HTML por caso de uso. Cada archivo es la interfaz: la pantalla ocupa todo el viewport (tema oscuro, minimal/flat) y la barra superior permite navegar entre mockups.

UC-01a
Landing — acceso público
Punto de entrada sin cuenta: propuesta de valor y accesos a «Iniciar sesión» y «Registrarse».
UC-01b
Iniciar sesión
Acceso con email y contraseña (hash bcrypt). La sesión expira a los 30 días.
UC-01c
Registrarse
Alta de cuenta por email y contraseña. La contraseña se almacena con hash (bcrypt).
UC-02
Crear nota
Lista de notas con creación instantánea desde «Nueva nota» (nota en blanco o plantilla).
UC-03
Editar nota · editor Markdown
Editor con vista previa en vivo, autoguardado a los 2 s («Guardado») e inclusión del flujo Markdown (include → Markdown).
UC-04
Gestionar carpetas
Carpetas anidadas, crear/renombrar/eliminar desde el menú contextual, y mover notas entre carpetas.
UC-05
Gestionar etiquetas
Crear/eliminar etiquetas y asignarlas o quitarlas de las notas.
UC-06
Buscar (full-text)
Búsqueda sobre título, contenido y etiquetas con resaltado de coincidencias (<300 ms · 10.000 notas).
UC-07
Compartir por link
Generar link público de solo lectura, opcionalmente protegido por contraseña.
UC-07b
Ingresar por link (invitado)
Un invitado abre el link público y entra al lugar de trabajo en modo solo lectura.
UC-09
Papelera / restaurar
Notas eliminadas permanecen 30 días; se pueden restaurar o vaciar la papelera manualmente.
UC-10
Configurar cuenta
Editar perfil (nombre, avatar), cambiar contraseña y preferencias de tema.
UC-12
Importar / Exportar
Exportar nota a Markdown o PDF e importar archivos .md como notas nuevas.
UC-13
Gestionar adjuntos
Subir imágenes/archivos (máx. 25 MB) sujeto al límite del plan (5/50 GB).
UC-14
Admin · ver usuarios y métricas
Listar usuarios, ver métricas de uso y gestionar cuentas (uso interno).

Abre cualquiera: la app se verá a pantalla completa, sin marco de navegador.
